ComicPad 설명서

1. 시작하기

설치

  • ComicPad 설치파일.exe 를 실행하면 설치할 폴더를 고르고, 바탕화면·시작 메뉴 바로가기와 "설치된 앱" 목록 등록까지 합니다. 관리자 권한은 필요 없습니다.
  • 필요한 프로그램도 함께 설치됩니다: ComicPad 전용 Python 이 설치 파일에 들어 있어 Python 을 따로 설치할 필요가 없습니다(ComicPad 폴더 안에만 들어가고 PC 에는 설치되지 않음). 전용 창에 쓰는 WebView2 는 Windows 11 에 기본으로 있고, 없는 PC 에서는 함께 들어 있는 마이크로소프트 WebView2 전체 설치본으로 인터넷 없이 설치합니다(그래도 안 되면 Edge 앱 창으로 열림).
  • 설치한 뒤에는 인터넷 없이 모든 기능이 동작합니다 (내장 AI 모델만 처음 한 번 받아야 함).
  • 이미 폴더째 가지고 있다면 폴더 안의 ComicPad 설치.bat 으로 바로가기만 만들 수도 있습니다.
  • 지우기: 시작 메뉴 > ComicPad > ComicPad 제거, 또는 Windows 설정 > 앱 > 설치된 앱. 작업한 그림(data 폴더)은 지우지 않습니다.

실행

  • 바탕화면의 ComicPad 아이콘(ComicPad.exe)을 누르면 PC 안에서만 도는 작은 프로그램(서버)이 켜지고 ComicPad 전용 창으로 열립니다. Windows 에 들어 있는 WebView2(Edge 엔진)를 쓰지만 Edge 창이 아니라서 주소창·브라우저 알림이 없고, 자기 아이콘으로 작업 표시줄에 뜹니다. 인터넷이 없어도 됩니다.
  • 창을 닫을 때 저장하지 않은 변경이 있으면 저장할지 묻습니다. 앱 안의 링크(모델 출처 등)는 기본 브라우저로 열립니다.
  • WebView2 런타임이 없는 예전 Windows 10 에서는 Edge 앱 창으로 대신 열립니다.
  • 한 번 열어 두면 서버가 꺼져 있어도 앱 화면은 열립니다 (도움말 > 앱으로 설치를 해 두면 시작 메뉴에서 바로).

처음 세팅 고르기 도움말 > 초기 세팅 프리셋 고르기

처음 켜면 익숙한 방식과 쓸 AI 기능을 고르는 창이 한 번 뜹니다. 기본은 클립스튜디오식입니다(창을 그냥 닫아도 클립스튜디오식). 나중에 도움말 메뉴에서 언제든 바꿀 수 있습니다.

세팅바뀌는 것

웹툰 (컬러)새 작품 추천 = 800px 폭 세로 긴 캔버스, 아래 막대에 웹툰 미리보기·아래로 늘리기·레이어·색.
S펜·터치 태블릿큰 버튼, 넓은 아래 막대, S펜 측면 버튼 = 원형 메뉴, 손가락 제스처.
간단히 (ComicPad 원래 화면)자주 쓰는 도구·메뉴만, 단축키는 ComicPad 기본.
  • 같은 키를 여러 도구가 쓰면 누를 때마다 다음 도구로 바뀝니다 (예: 클립스튜디오식의 G).
  • AI 기능 고르기: 같은 창 아래에서 쓸 AI 기능(사진→인형 자세, 선화 추출, 크기 키우기, 캐릭터 따기, 깊이, 탭해서 고르기)을 체크하면 그 모델만 받습니다(크기 표시, 상업용으로 쓸 수 있는 모델만). 나중에 AI > AI 기능 고르기·받기에서 더 받을 수 있습니다. 크기 키우기 모델은 설치 파일에 들어 있어 인터넷 없이 됩니다.
  • 적용하기 전 상태는 백업되어 도움말 > 세팅 되돌리기 한 번으로 돌아갑니다. 내가 만든 브러시·작업 화면·팔레트는 지우지 않습니다.
  • "~식"은 비슷한 손 배치를 뜻할 뿐, 해당 프로그램의 파일·아이콘을 쓰지 않습니다.

세팅 파일 주고받기 도움말 > 내 세팅 내보내기 / 세팅 가져오기

  • 단축키·화면 구성·브러시·작업 화면·팔레트·펜 설정·새 작품 추천 크기 중 고른 부분을 작은 .cpset 파일 하나로 저장합니다(그림은 안 들어감).
  • 받은 사람은 세팅 가져오기로 파일을 열고, 들어 있는 부분 중 원하는 것만 골라 가져옵니다. 브러시·작업 화면은 내 것에 합쳐지고, 가져오기 전 상태는 되돌릴 수 있습니다.
  • 그림 모양(이미지 팁) 브러시는 모양 그림 파일이 따로 있어야 합니다.

작업물은 어디에?

  • 설치 폴더 안 data 폴더: projects(작품) · exports(내보낸 그림) · assets(에셋) · versions(이전 저장본) · autosave(자동 저장) · trash(지운 파일).
  • 파일 > 저장 위치 에서 지금 어디에 저장되는지 볼 수 있습니다. 서버가 없을 때는 고른 폴더에, 그것도 없으면 이 기기(브라우저) 안에 저장됩니다.
모르는 기능은 Ctrl+K (기능 검색)에 이름 일부를 치면 바로 실행됩니다. F2 는 앱 안 기능 안내입니다.

2. 화면 구성

  • 왼쪽 도구 막대: 자주 쓰는 도구만 나와 있고, 끝의 … 에 나머지 도구가 있습니다.
  • 위 메뉴: 자주 쓰는 항목만 보이고, 메뉴 맨 아래 모든 항목 보기 로 전부 볼 수 있습니다.
  • 오른쪽 패널: 위(도구 설정·색·내비·페이지)와 아래(레이어·에셋·기록·애니). 가운데 경계를 끌어 크기 조절.
  • 아래 큰 버튼 막대: 실행취소·다시실행·브러시·지우개·스포이트·크기·농도·저장 등. 오른쪽 "편집"으로 버튼을 고릅니다.
  • 아래 상태줄: 그림 크기·현재 레이어·저장 상태·⏱ 작업 시간(누르면 진행표).

화면 꾸미기 보기 > 화면 꾸미기

  • 도구 막대에 꺼내 둘 도구, 메뉴 막대에 보일 메뉴와 각 메뉴 항목, 오른쪽 패널 탭을 직접 고릅니다.
  • 간단히 ↔ 모든 기능 보기 전환, 처음 상태로 초기화.
  • 작업 화면 저장 (보기 메뉴): 패널 배치·도구·브러시를 이름 붙여 저장하고 Ctrl+Alt+1~4 로 바꿉니다.

앱 밖 창으로 꺼내기

  • 패널 탭 줄 끝의 ⧉ 를 누르면 그 패널이 별도 창이 됩니다. 다른 모니터로 옮기거나 "항상 위" 작은 창으로 띄울 수 있고, 창을 닫으면 제자리로 돌아옵니다.
  • 환경 설정도 설정 창의 앱 밖 창으로 버튼으로 꺼낼 수 있습니다.
  • 브라우저가 팝업을 막으면 주소창의 팝업 허용을 눌러 주세요.

원형 메뉴

마우스 오른쪽 버튼(또는 설정에서 S펜 측면 버튼)을 누르면 펜 주위에 도구가 원형으로 뜹니다. 누른 채 방향으로 밀고 떼면 선택, 짧게 누르면 열린 채로 탭해서 고릅니다. 보기 > 원형 메뉴 편집 에서 8칸을 고릅니다.

3. 펜·태블릿·터치

S펜(갤럭시 북·갤럭시 탭), 와콤·휴이온·XP-Pen 같은 PC 용 펜 태블릿·액정 태블릿, 서피스 펜, 애플 펜슬(아이패드 Safari) 모두 같은 방식으로 됩니다.

  • PC 용 태블릿(와콤·휴이온·XP-Pen): 드라이버 설정에서 "Windows Ink" 를 켜야 필압·기울기가 옵니다. 꺼져 있으면 펜이 마우스로 들어와 필압이 없고, 그을 때 알림이 뜹니다("필압 없이 쓰기"로 굵기 고정도 가능).
  • 오른쪽 클릭(펜 길게 누르기 포함)을 하면 앱의 메뉴만 뜹니다. 웹페이지용 기본 메뉴는 나오지 않고, 글자 입력칸에서만 복사·붙여넣기 메뉴가 뜹니다.
  • 펜 버튼: 측면 버튼 = 스포이트(바꿀 수 있음), 두 번째 측면 버튼 = 화면 이동(바꿀 수 있음), 펜 뒤쪽 지우개 = 그동안만 지우개.
  • 기울기·돌림: tiltX/Y(와콤·S펜·서피스)와 애플 펜슬의 고도·방위각 모두 기울기로 씁니다. 와콤 아트 펜처럼 펜을 돌리는 각도(twist)가 오면 납작 펜 각도에 씁니다.
  • 아이패드 Safari: 두 손가락 확대로 페이지 전체가 커지거나, 길게 누르면 메뉴가 뜨는 것을 막았습니다. 같은 와이파이에서 PC 에 연결해 씁니다(내장 AI 는 그래픽 가속 없이 CPU 로).
  • 펜 필기감 진단 도움말 메뉴 / 설정 > 펜: 네 단계(자유롭게·가장 약하게·가장 세게·가만히)로 그어 보면 초당 점 개수·필압 범위·떨림을 재고, 이 펜에 맞는 값을 적용합니다.
  • 필기감 설정: 손떨림 보정(빠르면 덜, 느리면 더), 필압 다듬기, 펜을 대는 순간 굵게 찍힘 줄이기, 펜 위치 예측(지연 감소), 필압 곡선.
  • 측면 버튼: 누르고 그리면 스포이트(기본) / 지우개 / 화면 이동 / 원형 메뉴.
  • 손가락: 두 손가락 = 이동·확대·회전, 두 손가락 탭 = 실행취소, 세 손가락 탭 = 다시실행, 네 손가락 탭 = 패널 숨기기, 한 손가락 길게 = 스포이트.
  • 기본은 손가락으로 그려지지 않습니다(손바닥 오입력 방지). 위쪽 손가락 아이콘으로 켜고 끕니다. 펜을 뗀 직후 터치도 잠깐 무시합니다.

브러시 동작 브러시 도구 옵션

  • 동작 (기울기·속도·색): 펜을 눕힐수록 굵게/옅게, 빠를수록 옅게, 필압으로 배경색↔전경색, 찍을 때마다 색상·채도·명도 흔들기.
  • 종이 결: 브러시마다 종이 무늬(결 고운 종이·캔버스·수채지 등)와 세기·크기. "연필(종이 결)"·"수채(종이 결)" 프리셋.
  • 포토샵 브러시(.abr): 모양과 함께 크기·간격·각도·경도·흩뿌리기·필압 크기/불투명도·색 흔들림 설정도 읽어 옵니다.

펜 미리보기 · 필압 · 흔들림 보정 브러시 도구 옵션 / 설정 > 펜

  • 미리보기: 브러시 목록마다 작은 획 미리보기, 옵션 맨 위에 큰 미리보기(필압 약→강→약). 설정을 바꾸면 바로 다시 그려집니다.
  • 시험 그리기 칸: 옵션 안의 흰 칸에 펜으로 그려 보며 브러시를 고릅니다(그림에는 안 들어감).
  • 필압 곡선 편집기: 점을 끌어 곡선 모양을 바꾸고, 빈 곳 두 번 탭 = 점 추가, 점 두 번 탭 = 지우기. "부드럽게·딱딱하게·S자·약한 손힘…" 곡선 모음. 펜을 누르면 지금 필압이 곡선 위에 파란 점으로 보입니다. 설정 > 펜 = 모든 브러시 공통, 브러시 옵션 "이 브러시만 필압 곡선 따로" = 브러시마다.
  • 가장 약한 힘 / 가장 센 힘: 이보다 약하면 0, 이만큼만 눌러도 최대 (설정 > 펜).
  • 흔들림 보정 방식 (브러시마다): 자동(1€) · 평균 · 끈 당기기(펜이 끈 길이만큼 멀어질 때만 선이 따라옴, 그리는 동안 끈이 보임) · 무거운 펜(용수철처럼 살짝 늦게 부드럽게 따라옴). 세기 0~20.
  • 펜 끝까지 이어 그리기: 펜을 떼면 늦게 따라오던 선을 펜 끝까지 마저 그림 (끄면 늦은 자리에서 끝남).
  • 멈추면 직선: 선 끝에서 펜을 잠시 멈추면 시작점→끝점 직선으로 바뀌고, 그대로 움직여 끝점 조절(Ctrl = 15도 단위).
  • 브러시 커서 모양 (설정 > 펜): 크기 원 / 브러시 끝 모양(납작 펜은 기운 타원, 이미지 브러시는 그 모양, 부드러운 브러시는 진한 안쪽 표시) / 십자 / 점.

픽셀아트 파일 > 픽셀 아트 새로 만들기 · 필터 · 보기

  • 픽셀 연필 / 픽셀 지우개: 브러시 끝 "픽셀" — 계단 없는 네모 픽셀(1px 이상), 픽셀 퍼펙트(1px 선의 ㄴ자 겹친 모서리를 그리는 동안 지움).

  • 팔레트 색으로만 칠하기(작품마다): 브러시·채우기 색이 가장 가까운 팔레트 색으로, 반투명 가장자리는 없앰.
  • 색 수 줄이기(필터): 그림에서 N색 뽑기(미디언 컷) 또는 지금 팔레트로, 디더링 없음 · 격자 2×2/4×4 · 오차 확산. 뽑은 색을 팔레트로.

브러시 확장 브러시 도구 옵션

  • 듀얼 브러시: 두 번째 끝 모양(거친 결·원·점)이 닿은 곳만 남겨 마른 붓·거친 질감 (크기·찍는 수·퍼짐). 무늬는 문서에 고정이라 겹쳐 칠해도 결이 살아 있음. 프리셋 "마른 붓 (듀얼)".

6. 만화

  • 컷 나누기 K: 사각·대각선·다각형 컷, 페이지 틀. 컷 밖은 가려짐.
  • 말풍선 F: 드래그로 크기 → 꼬리 끝 탭. 만든 뒤에도 탭해서 이동(대사도 함께)·크기·꼬리·모양·색 수정, 겹친 풍선과 이어 붙이기(외곽선 하나로).
  • 텍스트 T: 다시 편집 가능한 글자. 세로쓰기, 외곽선, 자간, 문장부호 좁게, 루비({漢字|かんじ} 처럼 쓰면 읽는 법이 작게 붙음). data/fonts 에 글꼴을 넣거나 파일 > 글꼴 파일 추가.
  • 대본 배치 도구: 대사를 한꺼번에 넣고(한 줄 = 말풍선 하나) 탭할 때마다 놓기, 또는 컷 순서대로 자동 배치. 이름: 대사는 이름을 빼고, (생각) 구름, ! 외침, # 나레이션 상자.
  • 밑색 한 번에 칠하기 만화 메뉴: 선화로 닫힌 영역마다 다른 색으로 채운 밑색 레이어.
  • 색 점으로 칠하기 만화 메뉴: "색 힌트 레이어 만들기" → 영역마다 칠할 색으로 점이나 짧은 선을 찍기 → "색 점으로 칠하기". 영역마다 가장 많이 찍힌 색으로 채우고, 점이 없는 영역은 가장 많이 맞닿은 이웃 색을 따라갑니다(끌 수 있음). 결과는 "밑색 (색 점)" 레이어, 점을 고쳐 다시 하면 같은 레이어가 바뀝니다. 힌트 레이어는 내보내기에 안 나옵니다. (AI 아님, 크리타 색칠 마스크와 비슷)
  • 틈 막기 채우기·자동 선택·밑색·색 점: 이 너비(px)까지의 빈틈은 선이 이어진 것으로 보고 틈 너머로 칠하지 않습니다. 0~50px 마음대로 (보통 3~5, 러프는 10~20). 틈 너머로 조금 번지던 것도 고쳤습니다.
  • 집중선·유선·효과선, 망점 톤(플러그인).
  • 메모 핀 Y: 그림 위에 피드백 메모(색·해결됨 표시), 내보내기에는 안 나옴.
  • 여러 페이지 작품 만화 > 새 작품: 페이지 패널에서 넘기기(PageUp/PageDown), 카드를 끌어 순서 바꾸기.
  • 진행표: 페이지마다 콘티→선화→채색→완료, 작업 시간 자동 측정, 마감일·하루 몇 쪽.
  • 원고 설정: B5·A5·B6·A4·투고 B4 → 재단선·도련·안전선 가이드.
  • 효과음 글자 만화 > 효과음 글자 도구: "쾅!", "두근" 같은 의성어를 아치·물결·원근·흔들림·통통으로 휘고, 글자마다 크기·각도·위치를 따로, 안쪽·바깥쪽 2중 외곽선, 그라데이션, 기울기, 자간, 세로쓰기. 모양 모음(쾅!·두근·스윽·ドーン·파바박·휘익). 다시 탭하면 언제든 고치고, 변형 도구로 크기·회전·원근을 줘도 글자 정보가 남습니다. 붓으로 다듬으려면 "그림으로 바꾸기". 내 글꼴(data/fonts)도 됩니다.
  • 컷 나누기 템플릿 만화 메뉴: 1컷·2단·3단·4컷·2×2·계단·큰 컷+2칸·대각선·사선·웹툰 세로 컷 등을 골라 바로 넣기. 원고 설정이 있으면 안전선(또는 재단선)에 맞추고, 칸 사이 간격은 직접. 지금 페이지의 컷을 내 템플릿으로 저장·이름 바꾸기·지우기, 세팅 파일(.cpset)로 주고받기.
  • 인쇄·투고 전 점검 만화·파일 메뉴: 해상도(흑백 600dpi·컬러 300dpi), 캔버스가 도련보다 작음, 재단선 그림이 도련까지 안 이어짐, 안전선 밖 글자·말풍선, 7pt 보다 작은 글자, 없는 글꼴, 흑백 원고의 회색·섞인 컬러, 보이는 러프 레이어, 비상업 AI, 빈 페이지를 한 번에 찾아 목록으로. "가서 보기"로 그 자리로, 러프는 "밑그림으로", 회색은 "2값화 조정 레이어"로 바로 고치기. 여러 페이지 작품은 전체 페이지를 점검.

  • 복구 브러시: 스팟 복구(그냥 문지르면 주변에서 비슷한 곳을 골라 씀) / 복구 브러시(Alt+클릭으로 원본). 결(무늬)은 원본에서, 색·밝기는 그 자리 주변에 맞춰 잡티·먼지·흉터를 지웁니다.

  • 시점·화각·부감/앙각·빛 방향·음영 단계·선 굵기.
  • 만화에 넣기: 원고 크기 그대로 색·음영·선화 레이어로, 퍼스 자도 시점 그대로 만들어짐.
  • 인형은 팔다리가 끝으로 갈수록 가늘어지는 사람 모양입니다.
  • 동작 파일(BVH) 불러오기: 모션 캡처 .bvh 파일을 인형에 입히고 프레임 막대로 자세 고르기(관절 이름이 달라도 흔한 이름은 알아봄).
  • 애니메이션 프레임으로: BVH 동작·카메라 한 바퀴를 원하는 장수만큼 렌더해 애니 패널 "3D 애니" 폴더로.

버튜버 AI 메뉴 > 버튜버 스튜디오

  • 아바타 만들기 (버튜버 아바타 만들기): 캐릭터를 부위별 레이어로 그려 두면(몸·얼굴·뒷머리·앞머리·눈 뜸/감음·눈동자·눈썹·입 닫힘/벌림·볼터치·액세서리, 있으면 입 ㅏㅣㅜㅔㅗ) 레이어 이름으로 부위를 짐작해 줍니다. 틀린 것만 고르고, 깊이(클수록 고개 방향으로 더 움직임)를 바꿀 수 있습니다. PSD 로 그린 캐릭터도 열어서 그대로 쓰면 됩니다.
  • 움직임: 고개 좌우·위아래(부위 깊이에 따른 입체감)·기울기, 눈 깜빡임(추적 안 할 때는 자동), 눈동자, 눈썹, 입 벌림·모양, 숨쉬기, 머리카락 흔들림(용수철).
  • 웹캠 얼굴 추적: "카메라 얼굴 추적 켜기" — 표정·고개를 그대로 따라 합니다(MediaPipe 얼굴 모델, AI 모델 관리 또는 처음 세팅에서 "버튜버 얼굴 추적" 받기, 3.8MB). 영상은 이 PC 안에서만 쓰고 저장·전송하지 않습니다. "거울처럼", 움직임 크기·입 민감도·부드럽게 조절.
  • 마이크: 말소리 크기로 입이 움직입니다(카메라 없이도). PNG 버튜버: "PNG: 가만히 / 말할 때 / 눈 감음" 그림 몇 장만 정하면 말할 때 그림이 바뀌고 살짝 튑니다.
  • 표정: "표정" 레이어에 1~9 키를 주면 스튜디오(와 방송 창)에서 숫자 키로 켜고 끕니다. 0 = 기본.
  • 방송: "방송 창 열기" → 캐릭터만 보이는 창(초록·자홍·파랑 배경). OBS 에서 "창 캡처"로 이 창을 잡고 색 키(크로마 키)로 배경을 빼세요. 본 창을 내려도 방송 창은 계속 움직입니다.
  • 녹화·사진: MP4(안 되면 WebM, 마이크 소리 포함)·PNG 를 data/exports 에. .cpvt 아바타 파일로 저장해 두면 작품 없이 그 파일만 열어 방송할 수 있습니다.
  • 카메라·마이크는 ComicPad 창(이 PC)에서만 됩니다. 와이파이로 연결한 태블릿·휴대폰에서는 브라우저 보안 규칙(https 필요) 때문에 안 됩니다.

9. 애니메이션

  • 타임라인 (트랙 × 프레임): 애니 패널의 격자. 줄 = 트랙(애니메이션 폴더), 칸 = 프레임. 트랙을 여러 개 만들어 몸·팔·배경을 따로 움직입니다 (애니 > 트랙 추가).
  • 칸: 그림이 있는 칸 = 새 그림, 옅은 띠 = 앞 그림 이어 보이기(길게), 점선 테두리 = 연결된 칸(다른 프레임과 같은 그림 — 하나 고치면 같이 바뀜), 빈 칸 = 안 보임(두 번 누르면 새 그림).
  • 프레임 추가: +빈(새 그림) · +복제(지금 그림 복사) · +연결(같은 그림 이어 쓰기). 지금 트랙만 새 그림을 받고 다른 트랙은 앞 그림이 이어집니다. 연결 끊기·칸 비우기·칸 옮기기.
  • 프레임 길이: 지금 그림을 1·2·3·4·6·8장 동안, 또는 프레임마다 ms 로 따로(Aseprite식).
  • 태그(구간): "걷기 1~8" 처럼 이름을 붙이고 정방향·역방향·핑퐁으로 반복. "이 구간만 재생", 내보낼 때 구간 고르기.
  • 어니언 스킨: 앞뒤 0~5장, 앞·뒤 색, 진하기, 멀수록 옅게. 같은 그림을 길게 보여 주는 칸은 건너뛰고 다른 그림만.
  • 라이트 테이블: 원화·기준 그림을 올려 두면 어느 프레임에서나 흐리게 보임 (내보내기에는 안 나옴).
  • 타임시트(노출표) 애니 메뉴: 프레임 × 트랙 표에 그림 번호를 적어 타이밍 고치기("|" = 이어 보이기), CSV 저장.
  • 스프라이트 시트: 격자·가로·세로 배치, 여백, 투명 가장자리 잘라내기, Aseprite 형식 JSON(프레임 위치·시간·태그)을 함께 저장 → Unity·Godot·Phaser 등 게임 엔진. 시트 가져오기(칸 수·칸 크기·JSON으로 자르기).
  • Aseprite 파일 열기 (.aseprite/.ase, 파일 > 열기에서도): 레이어 → 트랙, 연결 셀, 프레임 시간, 태그, 팔레트(“팔레트로 쓰기”). 타일맵 레이어·슬라이스는 아직 못 읽습니다.
  • 움짤 만들기 애니 메뉴 / 애니 패널: 누르면 바로 GIF 로 (지난 설정 그대로, 처음엔 50%·무한 반복). 내보내기 (형식 고르기)에서 GIF · WebP(작고 선명, 투명) · APNG(색 그대로, 투명) · MP4(SNS 용) · WebM · PNG 연번, 크기·구간·반복 횟수·배경 투명·GIF 색 수·디더링·WebP 화질을 고르고, 예상 파일 크기를 미리 보여 줍니다.
  • 모션 경로 (트윈) 애니 > 모션 경로 도구: 트랙의 그림을 끌어 프레임마다 위치 키를 찍으면(Shift = 회전, Alt = 크기) 사이 프레임은 이징(천천히 출발·정지, 통통 튐, 직접 곡선 등)을 따라 자동으로 움직입니다. 원고 위에 경로와 키(네모)가 보이고 끌어서 고칩니다. 그림은 그대로 두고 그릴 때만 움직이며, "그림으로 굳히기"로 프레임마다 그림을 만들 수 있습니다. 내보내기·어니언 스킨에도 반영됩니다.
  • 립싱크 (입 모양 자동) 애니 패널, 소리가 있을 때: 입 모양 그림(닫힘·반·ㅏ·ㅣ·ㅜ)을 트랙 하나에 그리고 모양마다 그림을 고르면, 소리의 크기와 높낮이를 분석해 그 트랙의 칸을 자동으로 채웁니다(너무 짧게 바뀌지 않게 2장 이상 유지). 대략 고르는 것이라 끝나고 다듬으세요.
  • 소리: 음악·대사·효과음 파일 하나를 붙여 재생과 함께 듣기, 프레임 막대에 소리 모양 표시, 프레임을 넘길 때 그 부분만 짧게 들림, 시작 위치·음량. WebM 으로 내보내면 소리도 들어갑니다.
  • 카메라: 프레임마다 위치·확대·회전 키를 찍으면 사이 프레임은 부드럽게 이어짐(팬·줌·회전). 화면에 카메라 틀 표시, 내보낼 때 적용.
  • 내보내기: GIF · WebM 동영상 · PNG 연번.
  • 타임랩스 보기 메뉴: 기록을 켜면 그릴 때마다 장면을 찍어 두었다가 동영상으로.

10. 내보내기·인쇄

  • 전자책 (EPUB 3 / CBZ) 파일 메뉴: 지금 그림 또는 여러 페이지 작품 전체 → 고정 레이아웃 EPUB(한 쪽 = 그림 한 장, 펼침면 좌우, 오른쪽→왼쪽 넘김 선택) 또는 만화 뷰어용 CBZ(ComicInfo 포함). 원고 설정이 있으면 재단선 안쪽만.
  • 이미지 내보내기 Ctrl+Shift+E: PNG/JPG, 배율, 투명 배경, 원고 설정이 있으면 재단선/도련/전체.
  • 인쇄용 내보내기: PDF 한 파일 / 1비트 흑백 TIFF / PNG, 흑백 기준값 또는 디더링, 여러 페이지 작품 전체.
  • CMYK 인쇄: 인쇄소가 준 ICC 프로파일(또는 Windows 에 설치된 프로파일)로 CMYK 변환 → CMYK TIFF(프로파일 포함) / CMYK PDF(출력 의도 포함). 지각적·상대 색도 선택.
  • 인쇄 색 미리보기 보기 메뉴: 화면에서 CMYK 로 찍혔을 때 색을 흉내 내고, 인쇄로 못 내는 색은 표시.
  • 웹툰 플랫폼 규격: 가로폭 맞춤 → 세로로 나누기(되도록 컷 사이 빈 곳) → 장당 용량에 맞춰 압축. 규격은 바뀔 수 있으니 올리기 전 공지 확인.
  • 웹툰 분할, 레이어별 내보내기, PSD 열기·저장(레이어·폴더·마스크 유지, 열 때 레벨·곡선·밝기/대비·색조/채도·반전·포스터화·한계값·흑백 조정 레이어는 조정 레이어 그대로). 글자 레이어는 포토샵에서 다시 고칠 수 있는 글자로, 컷·말풍선·벡터 레이어는 셰이프 레이어(모양·색·선을 포토샵에서 고칠 수 있음)로 저장. 열 때 그라데이션 맵·색상 균형 조정 레이어와 그림자·획 효과도 가져옵니다.
  • 펼침면 미리보기(책처럼 두 쪽, 넘김 방향), 웹툰 미리보기(휴대폰 폭).
  • 에셋: 레이어·선택 영역을 투명 PNG 에셋으로 저장해 에셋 패널에서 끌어 쓰기. 포토샵 브러시(.abr) 가져오기.

11. 저장·백업·협업

  • 작업물 자동 백업 파일 > 작업물 백업: 하루 한 번(간격 바꿀 수 있음) 작품·에셋·글꼴·설정을 zip 하나로 묶어 dataackups 에 두고 최근 14개만 남깁니다. 구글 드라이브 사본이 켜져 있으면 드라이브의 ComicPad\백업 에도 한 부. 목록에서 작품 하나를 "(복원 날짜)" 새 파일로 꺼낼 수 있습니다(지금 파일은 덮어쓰지 않음).
  • 자동 저장(설정에서 간격), 비정상 종료 후 다시 켜면 복구 제안.
  • 버전 기록 파일 메뉴: 저장할 때마다 이전 판 보관(작품마다 30개). 따로 열기·되돌리기·비교(밀어서·겹쳐·달라진 곳 빨갛게·나란히).
  • 저장 충돌 감지: 연 뒤에 다른 곳에서 같은 작품이 저장됐으면 알리고, 덮어쓸지 묻습니다.
  • 구글 드라이브 사본 파일 > 저장 위치: Google Drive 데스크톱 앱의 내 드라이브\ComicPad 로 저장할 때마다 복사. 다른 PC 에서 저장한 것은 "드라이브에서 가져오기".
  • 휴대폰·태블릿 도움말 > 휴대폰·태블릿 연결: 같은 와이파이에서 QR 로 연결(보안 키 필요). 연결이 끊기면 기기에 임시 저장.
  • PC 없이 휴대폰·태블릿만으로: 휴대폰 브라우저로 https://39nhs.github.io/comic_pad/ 를 열고 "홈 화면에 추가(앱 설치)". 한 번 열면 인터넷 없이도 열리고 작품은 그 기기 안에 저장됩니다. AI·PC 폴더 저장·자동 백업은 PC 버전에서만 됩니다.
  • ARM 노트북(스냅드래곤 등): 설치 파일이 알아서 ARM 용 Python 을 설치합니다.
  • 피드백 파일: 러프·메모만 작은 .cpfb 파일로 보내고, 받은 쪽은 자기 원고 위 "피드백" 폴더로 얹어 봄.
  • 업데이트: 켤 때 하루 한 번 새 버전을 확인해 알려 줍니다(인터넷이 있을 때만). 도움말 > 업데이트 확인에서 직접 확인하거나 자동 확인을 끌 수 있습니다. 만든 사람의 서명이 맞는 파일만 받고, 그린 그림·설정(data 폴더)은 건드리지 않습니다. 바꾸기 전 프로그램은 data\updates 에 남겨 두고, 문제가 있으면 같은 창에서 이전 버전으로 되돌리기를 할 수 있습니다. 업데이트 뒤 처음 켤 때 바뀐 점을 보여 줍니다.
  • 문제 보내기 (도움말): 버전·환경·최근 오류를 모아 보여 줍니다. 확인하고 고친 뒤 복사하거나 GitHub 에 올리세요. 자동으로 보내지는 않습니다.
  • 창을 닫으면 뒤에서 돌던 ComicPad 서버(python)도 같이 꺼집니다. 휴대폰 연결을 켜 두었으면 휴대폰이 계속 쓸 수 있게 서버는 남습니다. 설치 파일을 실행할 때 ComicPad 가 켜져 있으면 먼저 끄고(저장 안 한 작업은 창이 물어봄) 설치합니다.

13. 기능 추가하기 (플러그인)

  • 설치 폴더의 plugins 에 .js 파일 하나를 넣으면 켤 때 불러옵니다(이름이 _ 로 시작하면 꺼짐). 명령·메뉴·도구·패널을 추가할 수 있습니다 — plugins/README.md 참고.
  • 앱 자체는 app/js 의 파일을 직접 고칠 수 있습니다(빌드 과정 없음).

14. 문제가 생기면

  • 도움말 > 자동 점검: 주요 기능 42가지를 시험용 그림에서 돌려 보고 결과를 표로 보여 줍니다(작업 중인 그림은 그대로).
  • 앱이 안 열림: Python 이 설치되어 있는지, 바탕화면 아이콘으로 열었는지 확인. 서버 없이 열렸으면 위쪽 알림의 저장 위치를 확인하세요.
  • 창이 갑자기 닫혔음: 다시 켜면 자동 저장본 복구를 제안합니다. 파일 > 자동 저장 복구, 버전 기록도 확인.
  • 펜이 이상함: 도움말 > S펜 필기감 진단 → 추천값 적용, 어색하면 "기본값으로".
  • 아주 큰 원고(B4 600dpi 등)에서 느림: 메모리 절약이 한동안 안 쓴 레이어를 압축해 둡니다(아래 막대 "💤 레이어 n개 절약 중", 레이어를 고르면 바로 돌아옴). 설정 > 큰 원고 메모리 절약에서 자동/항상/끄기, 보기 > 지금 압축. 그래도 무거우면 다 그린 레이어를 병합하세요.
  • 앱 밖 창이 안 열림: 브라우저 주소창에서 팝업 허용.

15. 아직 없는 기능

  • 여러 사람이 동시에 같은 원고 편집(실시간 협업), 클라우드 계정. 지금은 구글 드라이브 사본·피드백 파일로 주고받습니다.
  • 아이패드 Safari: 일부 기능(폴더 직접 저장 등)이 안 됩니다.
  • AI 모델: 탭 선택(MobileSAM)·크기 키우기 모델만 설치 파일에 들어 있고, 나머지는 처음에 AI 모델 관리에서 받아야 합니다(인터넷 필요). 일부는 PyTorch 가 있는 PC 에서만 변환해 쓸 수 있고, RMBG 는 약관 동의 후 직접 받아야 합니다. 그림을 새로 그려 주는 생성형 AI 는 넣지 않았습니다(따로 설치한 SD WebUI 연결만).
  • CMYK: 프로파일로 변환해 내보내기·미리보기는 되지만, 그리는 동안 CMYK 로 작업하지는 않습니다(RGB 로 그리고 내보낼 때 변환).
  • PSD: 레이어 효과는 그림자·획·외부 광선만 읽습니다(그 밖은 빠짐). 저장한 셰이프는 곡선도 점을 이은 모양이고, 벡터 선의 브러시 질감은 셰이프에 없습니다(같이 저장한 그림에는 있음).

# ComicPad — 내 맘대로 고쳐 쓰는 만화 그림판

설치할 것 없음. Python(이미 설치됨) + Edge 로 돌아갑니다. 모든 작업물은 이 폴더(`G:\claude\comicpad\data`)에 저장됩니다.

## 설명서
- **ComicPad 설명서**: 앱의 도움말 > ComicPad 설명서, 또는 `app/manual.html` 을 브라우저로 열기 (찾기·인쇄 가능). 설치하면 시작 메뉴에도 생김

## 설치 파일 (다른 PC 에 설치할 때)
- `dist\ComicPad 설치파일.exe` 하나만 옮겨서 실행 → 설치 폴더 고르기(기본: 내 계정의 Programs\ComicPad, G 드라이브 등 다른 곳도 가능) → 바로가기·앱 목록 등록
- 이미 설치된 PC 에서 실행하면 같은 자리에 새 버전으로 업데이트 (작업물 data 폴더는 그대로)
- **필요한 프로그램도 함께 설치**: Python 3.12 내장형(ComicPad 폴더 안 `python\`, PC 에 따로 설치하지 않음)이 들어 있어 Python 없는 PC 에서도 바로 됨.
  WebView2(전용 창)는 Windows 11 엔 기본, 없으면 함께 넣은 마이크로소프트 WebView2 전체 설치본(205MB)으로 인터넷 없이 설치 (안 되면 작은 설치기로 재시도, 그래도 안 되면 Edge 앱 창)
- 설치 파일 약 250MB. 설치 뒤에는 인터넷 없이 동작 (내장 AI 모델만 처음 한 번 받기 필요, 크기 키우기 모델은 들어 있음)
- 함께 넣는 파일은 `redist\` (python-3.12.10-embed-amd64.zip, MicrosoftEdgeWebView2RuntimeInstallerX64.exe, MicrosoftEdgeWebview2Setup.exe — 각각 Python Software Foundation·마이크로소프트 서명 확인)
- 설치 파일 다시 만들기: `powershell -ExecutionPolicy Bypass -File installer\build_setup.ps1` (Windows 기본 도구 IExpress 사용)

## 설치 / 실행 (이 폴더에서 바로)
- **설치**: `ComicPad 설치.bat` 더블클릭 → 바탕화면·시작 메뉴 바로가기 생성, Windows "설치된 앱" 목록 등록 (관리자 권한 필요 없음, Python 이 없으면 설치 여부를 물어봄)
- **실행**: 바탕화면의 **ComicPad** 아이콘 = `ComicPad.exe` (전용 창: 서버를 켜고 WebView2 로 ComicPad 만의 창을 띄움, Edge 창·주소창·브라우저 알림 없음)
  `server.py` 를 직접 켜도 ComicPad.exe 가 있으면 전용 창으로 열림. 실행 창 소스는 `launcher/` (`launcher\build.ps1` 로 다시 만들기, WebView2 SDK 파일은 마이크로소프트 서명 그대로)
- **제거**: `ComicPad 제거.bat` 또는 Windows 설정 → 앱 → 설치된 앱 → ComicPad. 바로가기와 등록만 지우고 작업물(data)은 남김
- 폴더를 다른 곳으로 옮겼다면 `ComicPad 설치.bat` 을 다시 실행하면 바로가기가 새 위치로 바뀜
- **창을 닫으면 서버(python)도 같이 꺼짐** (휴대폰 연결이 켜져 있으면 휴대폰이 쓸 수 있게 서버는 남음).
  설치 파일은 ComicPad 가 켜져 있으면 먼저 창을 닫고(저장 안 한 작업은 창이 물어봄) 그 폴더의 서버만 끈 뒤 설치

## 자동 업데이트 (GitHub 릴리스)
- 켤 때 하루 한 번 https://github.com/39nhs/comic_pad 의 최신 릴리스를 확인 → 새 버전이면 알림 → **받아서 적용 → 지금 다시 시작**.
  도움말 > 업데이트 확인 에서 직접 확인·자동 확인 끄기. 인터넷이 없으면 아무 일도 안 함
- 안전장치: 릴리스의 `update.json` 은 만든 사람의 **서명(RSA-3072)** 이 맞아야 믿고, 받은 꾸러미는 그 안의 **SHA-256** 과 같아야 적용.
  `data`·`python` 폴더는 절대 건드리지 않고, 바꾸기 전 파일은 `data\updates\ComicPad_이전판_<버전>.zip` 에 남김 (최근 3개).
  실행 중이라 잠긴 파일(ComicPad.exe, DLL)은 옆으로 비켜 두고 바꾼 뒤 다음 시작 때 지움. 창 프로그램이 바뀐 업데이트는 창을 껐다 켜야 반영
- 버전: 루트의 `VERSION` 파일
- **릴리스 만드는 법** (만드는 사람 PC):
  1. 처음 한 번 `python tools/make_release.py --genkey` → 비밀키 `%USERPROFILE%\.comicpad\release_key.json` (**저장소에 넣지 말고 따로 백업**, 잃어버리면 이미 설치된 ComicPad 는 새 업데이트를 못 받음) + 공개키 `release_pubkey.json`(앱과 함께 배포)
  2. `VERSION` 숫자 올리기 (예: 1.1.0 → 1.1.1)
  3. `python tools/make_release.py --notes "바뀐 점" --upload --installer` → `dist\release\` 에 꾸러미·update.json·서명을 만들고 GitHub 릴리스 `v<버전>` 으로 올림 (gh 로그인 필요, `--installer` 는 설치파일도 같이)
  - 꾸러미에는 프로그램 파일만 (약 13MB). 내장 AI 모델까지 바꿨으면 `--with-models`

## 처음 세팅 고르기 · 세팅 파일 주고받기 (도움말 메뉴)
- **처음 켜면 한 번** 세팅을 고르는 창: **클립스튜디오식(기본, 흑백 만화, B5 600dpi 원고 추천)** / 포토샵식(일러스트, 모든 메뉴) /
  웹툰(컬러, 세로 긴 캔버스) / S펜·터치 태블릿(큰 버튼, 원형 메뉴) / 간단히(ComicPad 원래 화면). 창을 그냥 닫아도 클립스튜디오식. 이미 쓰던 설정이 있으면 뜨지 않음
- 같은 창에서 **쓸 AI 기능을 체크** → 그 모델만 받음 (크기 표시, 상업 가능 모델만). 나중엔 AI > AI 기능 고르기·받기.
  크기 키우기 모델(Real-ESRGAN, 변환본)은 설치 파일의 `models_bundled` 에 들어 있어 인터넷·PyTorch 없이 됨
- 도구 키도 바꿀 수 있고(같은 키를 여러 도구에 주면 누를 때마다 차례로), 새 작품 창 맨 앞에 "추천" 크기가 나옴
- 적용 전 상태는 백업 → **세팅 되돌리기** 한 번으로 복구. 내가 만든 브러시·작업 화면·팔레트는 지우지 않음
- **내 세팅 내보내기 / 세팅 가져오기**: 단축키·화면 구성·브러시·작업 화면·팔레트·펜 설정·추천 크기 중 고른 것만 `.cpset` 파일로 주고받기
  (브러시·작업 화면은 합치기, 그림은 안 들어감)
- "~식"은 손 배치가 비슷하다는 뜻일 뿐, 해당 프로그램의 파일·아이콘은 쓰지 않음

## 폴더
| 폴더 | 내용 |
|---|---|
| `data/projects` | 프로젝트(.cpad) + 미리보기 |

| `data/config/settings.json` | 브러시 프리셋, 팔레트, 퀵바, 단축키 등 설정 |
| `data/trash` | 삭제한 파일 (영구 삭제 안 함) |
| `plugins` | 기능 추가용 플러그인 (`plugins/README.md`) |
| `app` | 앱 본체 코드 |

## 주요 기능
- **브러시**: G펜·마루펜·연필·러프 연필(파랑)·마커·에어브러시 등, 필압(크기/농도), 손떨림 보정, 프리셋 복제/저장, 에셋 이미지 스탬프 브러시
- **레이어**: 클리핑, 투명 잠금, 합성 모드, 밑그림(내보내기 제외), 레이어 컬러(파란 선), 끌어서 순서 변경
- **만화**: 페이지 컷 만들기 → 선을 그어 컷 자르기, 컷 탭하면 그 안만 선택, 말풍선(타원/사각/외침/생각 + 꼬리), 다시 편집되는 텍스트(세로쓰기, 외곽선)
- **러프**: 러프 레이어(파란 선 + 반투명 + 내보내기 제외), 화면 좌우 반전, 대칭 그리기
- **에셋**: 레이어/선택/보이는 그림을 투명 PNG로 잘라 저장, 에셋 패널에서 탭해서 배치
- **선택/채우기**: 사각·타원·올가미·자동선택, 틈 닫기·영역 확장 채우기, 선택 메뉴 막대
- **플러그인 예제**: 집중선 도구, 망점 톤
- **추가 도구**: 그라데이션(J), 올가미 채우기(L, 둘러싸서 밑색 깔기), 손끝 문지르기(W), 선택 펜(Q), 자유 변형(원근, 네 모서리)
- **자(R)**: 1·2·3점 투시, 평행선, 방사선, 동심원 — 그리기 시작한 방향에 가장 가까운 자에 선이 붙음
- **입출 보정**: 브러시 속성에서 선 시작/끝을 가늘게
- **대칭**: 좌우/상하/상하좌우/방사(N조각, 만다라)
- **레이어 마스크**: 레이어 패널 "+마스크" → 지우개로 가리고 브러시로 되살리기
- **참조 레이어**: 선화 레이어를 "참조"로 지정하면 채우기/자동선택이 그 선만 기준으로
- **내보내기**: PSD(레이어 유지), 웹툰 분할(JPG/PNG 여러 장), 레이어별 PNG
- **에셋 효과**: 외곽선 두르기(스티커), 그림자, 단색으로 바꾸기
- **패널**: 내비게이터(미리보기·확대·회전), 작업 기록(탭해서 그 시점으로), 참조 이미지 창(여러 개, 스포이트/반전/흑백)
- **임시 도구**: 도구 단축키를 누르고 있는 동안만 그 도구 (놓으면 원래 도구)
- **레이어 폴더**: 폴더 안에 폴더 가능, 폴더 불투명도/합성 모드, 끌어서 폴더 안에 넣기(폴더 줄 가운데에 놓기), Ctrl+G 로 묶기, 폴더 합치기
- **PSD 열기**: PSD/PSB, 1·8·16·32비트, RGB·CMYK·흑백·Lab·인덱스·비트맵, 레이어·폴더·마스크·불투명도·합성 모드 (창에 파일을 끌어다 놓아도 열림)
- **PSD 저장**: 레이어·폴더·레이어 마스크(켜짐/꺼짐) 유지
- **사선/다각형 컷**: 자르기 선을 비스듬히 그으면 사선 컷, "다각형" 모드로 꼭짓점을 찍어 자유 모양 컷
- **애니메이션**: 애니 탭 → 애니메이션 폴더 안 레이어 = 프레임, 어니언 스킨(앞/뒤 잔상), 재생, GIF / WebM 동영상 / PNG 연번 내보내기 ( , . 키로 이전/다음 프레임, Shift+Enter 재생)

## 보정 · 일러스트 · 만화 (포토샵/클립스튜디오식)
- **보정 메뉴**: 레벨, 톤 커브(곡선, 채널별), 색조/채도/명도, 색상 균형, 밝기/대비, 자연 채도, 그라데이션 맵, 단색 입히기, 흑백, 포스터화, 2값화, 반전 — 실시간 미리보기
- **조정 레이어**: 위 보정을 원본을 건드리지 않는 레이어로 (더블탭으로 값 수정, 클리핑하면 바로 아래 레이어만, 마스크 가능)
- **필터**: 언샤프 마스크, 노이즈, 모자이크, 방향 흐림, 방사형(줌) 흐림, 빛 번짐
- **보정 도구**: 복제 도장(S, Alt+클릭으로 원본), 흐림/선명 브러시, 픽셀 유동화(밀기·부풀리기·오므리기·회전)
- **브러시**: 수채/유화 혼색, 색 섞기, 브러시 합성 모드(닷지 발광·곱하기 그림자·오버레이 빛 등), 스프레이, 캘리그래피 펜(S펜 기울기)
- **레이어 효과**: 테두리, 그림자, 외부 광선 — 그림을 고쳐도 효과가 따라옴
- **톤화 레이어**: 회색으로 칠하면 망점(점/선, 간격, 각도)으로 보이고 그대로 내보내짐
- **선택**: 색역 선택(같은 색 전부), 경계 흐리기
- **만화 효과**: 유선 도구, 우니/베타/폭발 플래시
- **여러 페이지 작품**: 페이지 탭 → 새 작품, 페이지 넘기기(PageUp/Down, 자동 저장), 페이지 추가/복제, 전체 PNG/JPG/PSD 내보내기
- **기능 검색**: Ctrl+K 또는 위쪽 돋보기 — 이름·초성(ㅌㅋ)·메뉴 이름으로 찾기
- **단축키 편집**: 도움말 → 단축키 편집
- **색**: HSV / RGB 슬라이더

## 휴대폰 · 태블릿
- 화면이 좁으면 자동으로 휴대폰 배치 (아래 버튼 막대, 가로 도구줄, 패널은 오른쪽 서랍, 메뉴 버튼 하나)
- 도움말 → "휴대폰·태블릿 연결 (QR)" → "휴대폰 연결 켜기" → 같은 와이파이의 휴대폰으로 QR 찍기
  - 작업은 PC(G: 드라이브)에 저장, 보안 키가 있어야만 접속 가능
  - 처음 켤 때 Windows 방화벽 창이 뜨면 "개인 네트워크" 허용
  - 휴대폰 브라우저 메뉴 → "홈 화면에 추가"로 앱처럼 사용
- PC 연결이 끊기면 기기에 임시 저장 → 파일 → "기기 임시 저장함"에서 PC로 보내기

## 서버 없이 쓰기 (오프라인)
저장 위치는 자동으로 골라집니다 (파일 → 저장 위치에서 확인·변경).
1. **PC 서버가 켜져 있으면**: 지금처럼 `data` 폴더에 저장 + 휴대폰 와이파이 연결
2. **서버가 없으면 허락한 폴더**: 파일 → 저장 위치 → "ComicPad 폴더 고르기"에서 `G:\claude\comicpad` 를 한 번 고르면,
   Python 없이 Edge 가 그 폴더에 직접 저장합니다 (서버 모드와 같은 파일, 버전 기록·휴지통도 똑같이).
   브라우저를 다시 켜면 "폴더 허락" 버튼을 한 번 눌러야 할 수 있습니다
3. **둘 다 없으면 이 기기 안**: 파일 → 기기 임시 저장함에서 다운로드하거나 나중에 PC 로 보내기

- 앱 파일은 처음 한 번 열 때 미리 받아 두므로, **서버가 꺼져 있어도 앱이 열립니다.**
  도움말 → "앱으로 설치"로 설치해 두면 시작 메뉴에서 바로 열 수 있습니다
- 휴대폰·태블릿 단독 사용(PC 없이)은 `app` 폴더를 https 주소(예: GitHub Pages)에 올려 거기서 한 번 설치해야 합니다.
  `app` 폴더는 그대로 올리면 되는 정적 파일입니다 (`python server.py --precache-only` 로 파일 목록 갱신)
- 서버 없이 안 되는 것: 탐색기로 폴더 열기, 휴대폰 와이파이 연결. 글꼴은 파일 → "글꼴 파일 추가"로 어느 모드에서나 추가 가능

## 구글 드라이브에 사본 저장
파일 → 저장 위치 · 구글 드라이브 → "켜기"
- 이 PC 에 깔린 **Google Drive 데스크톱 앱**의 `내 드라이브\ComicPad` 폴더(지금은 `D:\내 드라이브\ComicPad`)로 복사합니다.
  Google 계정 연동이나 API 키 없이 동작하고, 업로드는 Google Drive 앱이 알아서 합니다
- 작업은 계속 G: `data` 에 저장되고, 저장할 때마다 작품·에셋·내보낸 그림·글꼴이 드라이브에도 복사됩니다.
  휴대폰에서 PC 로 저장한 것도 복사되고, 지운 파일은 드라이브의 `ComicPad	rash` 로 옮겨집니다
- 다른 PC 에서 저장한 작품은 파일 → "구글 드라이브에서 가져오기" (지금 PC 의 것은 버전 기록에 남김)
- 서버 없이 쓸 때(폴더 모드)는 같은 화면에서 드라이브 폴더를 한 번 골라 두면 그쪽에도 사본이 생깁니다
- 휴대폰 ComicPad 가 PC 없이 드라이브를 직접 읽고 쓰는 것은 Google Drive API(OAuth) 가 필요해 지금은 안 됩니다
  (Google Cloud 프로젝트 설정 + https 주소 필요. 같은 와이파이 주소 http://192.168.x.x 는 Google 로그인에 쓸 수 없음)

## 그리기 보조 · 작업 관리 (추가)
- **S펜 필기감 진단** (도움말 메뉴 / 설정 > 펜): 4단계로 그어 보면 초당 점 개수·필압 범위·떨림·지연을 재고, 이 펜에 맞춘 값(필압 범위, 떨림 보정, 필압 다듬기, 위치 예측)을 적용
- **벡터 선 정리**: 지우개 "교차점까지"(삐져나온 선 끝만 지우기), 벡터 선 고르기 도구(단축키 O: 탭으로 고르기·끌어서 이동·다듬기·굵기·색·삭제)
- **대본 배치** (대본 배치 도구): 대사를 한꺼번에 넣고 탭할 때마다 말풍선+글자로 놓거나 컷 순서대로 자동 배치.
  `이름: 대사` 는 이름을 빼고, `(생각)` 구름, `!` 외침, `#` 나레이션 상자
- **밑색 한 번에 칠하기** (만화 메뉴): 선화로 닫힌 영역마다 다른 색(또는 한 색)으로 채운 "밑색" 레이어. 틈 닫기·선 아래까지 채움
- **명도 확인 보기** (Shift+Y): 화면만 흑백 → 5단계 명암 덩어리 → 끔 (그림은 그대로)
- **용지 질감** (레이어 패널 용지 줄의 "질감" / 보기 메뉴): 고운 종이·거친 수채지·캔버스 천·섬유 종이, 칠한 그림 위에도 결 보이기
- **원형 메뉴**: 마우스 오른쪽 버튼, 또는 설정 > 펜 > 측면 버튼을 "원형 메뉴"로. 누른 채 방향으로 밀고 떼면 선택, 보기 > 원형 메뉴 편집
- **작업 화면 저장** (보기 메뉴): 패널 탭·비율·왼손잡이·퀵바·아래 막대·도구·브러시를 이름 붙여 저장, Ctrl+Alt+1~4
- **타임랩스** (보기 메뉴): 기록을 켜면 그릴 때마다 장면을 찍어 두고 WebM 동영상으로 (장면은 이 브라우저 안에 보관)
- **진행표** (만화 메뉴 / 아래 상태줄의 ⏱): 페이지마다 콘티→선화→채색→완료, 작업 시간 자동 측정(2분 넘게 쉬면 멈춤), 마감일·하루 몇 쪽
- **페이지 순서 바꾸기**: 페이지 패널에서 카드를 끌어다 놓기, 펜·터치는 "앞으로/뒤로" 버튼 (`작품/story.json` 에 순서 저장)
- **버전 비교** (파일 > 버전 기록 > 비교): 밀어서 비교 / 겹쳐 보기 / 달라진 곳 빨갛게 / 나란히
- **피드백 파일** (파일 메뉴): 러프 레이어·메모 핀만 작은 `.cpfb` 파일로 보내고, 받은 파일은 내 원고 위 "피드백" 폴더로 (크기가 달라도 맞춤)

## 화면 구성 (간단히 / 꾸미기 / 앱 밖 창)
- **기본은 "간단히"**: 왼쪽 도구 막대에는 자주 쓰는 도구만, 나머지는 막대 끝 "…" 버튼. 메뉴도 자주 쓰는 항목만 보이고
  메뉴 맨 아래 "모든 항목 보기"로 전부. 어떤 기능이든 **Ctrl+K**(기능 검색)으로 바로 실행
- **화면 꾸미기** (보기 메뉴): 도구 막대에 꺼내 둘 도구, 메뉴 막대에 보일 메뉴와 항목, 오른쪽 패널 탭을 직접 고르기. "모든 기능 보기"로 전환, 초기화
- **앱 밖 창으로**: 패널 탭 줄 끝의 ⧉ 버튼, 또는 보기 > 패널을 앱 밖 창으로. 다른 모니터로 옮기거나 "항상 위" 작은 창으로.
  창을 닫으면 패널은 제자리로 돌아옴. 환경 설정도 앱 밖 창으로 열 수 있음 (설정 창의 "앱 밖 창으로")
  (브라우저가 팝업을 막으면 주소창의 팝업 허용을 눌러 주세요)
- **기능 안내** (F2, 도움말 메뉴): 무엇을 어디서 하는지 찾아보고 바로 열기
- **펜 미리보기·필압·흔들림 보정**: 브러시 목록 획 미리보기 + 큰 미리보기 + 시험 그리기 칸, 필압 곡선 편집기(전체/브러시별, 곡선 모음, 가장 약한·센 힘),
  흔들림 보정 방식 브러시마다(자동·평균·끈 당기기·무거운 펜), 펜 끝까지 이어 그리기, 멈추면 직선, 브러시 끝 모양 커서
- **픽셀아트**: 픽셀 연필·지우개(계단 없음, 픽셀 퍼펙트), 픽셀 격자·또렷하게 보기, 팔레트 색으로만 칠하기(작품마다), 색 수 줄이기(미디언 컷 + 격자/오차 확산 디더),
  팔레트 .gpl/.hex 가져오기·내보내기, 팔레트 색 바꾸기, 명암 잉크(같은 계열 색 사다리), 디더 무늬 브러시·채우기 (파일 > 픽셀 아트 새로 만들기)
- **브러시 확장**: 듀얼 브러시(두 번째 끝 모양으로 가리기), 리본(끝 모양을 획 따라 늘림), 종이 결 합성 방식(곱하기·빼기·문턱)
- **효과음 글자 도구** (만화 메뉴): 의성어를 아치·물결·원근·흔들림·통통으로 휘기, 글자별 크기·각도·위치, 2중 외곽선, 그라데이션, 기울기, 모양 모음. 글자 레이어(meta.sfx)라 다시 편집·변형 가능, PSD 에는 그림으로
- **컷 나누기 템플릿** (만화 메뉴): 15가지 배치 + 내 템플릿 저장(설정의 panelTemplates, .cpset 로 주고받기), 안전선·간격 맞춤, 사선 컷도 간격 유지
- **인쇄·투고 전 점검** (만화·파일 메뉴): 해상도·도련·안전선·작은 글자·없는 글꼴·회색·컬러·보이는 러프·비상업 AI·빈 페이지, 가서 보기·빠른 고치기, 작품 전체 페이지
- **자동 점검** (도움말 메뉴): 주요 기능 42가지를 시험용 그림에서 돌려 보고 결과 표. 작업 중인 그림과 실행취소 기록은 그대로

- **3D 손발 끌기**: 데생 인형에서 "손발 끌기" 모드로 손·발을 끌면 팔꿈치·무릎까지 자연스럽게 굽혀짐
- 타임랩스·애니 동영상을 만드는 중에 창이 가려지면 잠시 멈췄다가 다시 보이면 이어서 만듦

## 터치 / S펜 (Galaxy Book Flex 2)
- 손가락: 두 손가락 이동·확대·회전 / **두 손가락 탭 = 실행취소** / 세 손가락 탭 = 다시실행 / 네 손가락 탭 = 패널 숨기기 / 한 손가락 길게 = 스포이트
- 기본은 **손가락으로 안 그려짐**(손바닥 오입력 방지). 상단 손가락 아이콘으로 켜기/끄기
- 펜이 닿아 있거나 막 뗀 직후의 터치는 무시 (시간은 설정에서)
- S펜 측면 버튼 + 그리기 = 스포이트 (설정에서 지우개/화면 이동으로 변경)
- 왼쪽 **퀵바**: 손잡이 끌기 = 이동, 손잡이 탭 = 버튼 고르기
- 설정 → "필압 곡선"에서 S펜 필압 감도 조절 + 테스트

> Windows 의 펜 "길게 누르기 = 오른쪽 클릭"이나 펜 플릭이 거슬리면
> Windows 설정 → Bluetooth 및 장치 → 펜 및 Windows Ink 에서 끌 수 있습니다.
>
> 오른쪽 클릭(펜 길게 누르기 포함)은 앱의 메뉴만 뜹니다. 웹페이지용 기본 메뉴(뒤로·새로고침·검사 등)는
> 전용 창과 앱 안 모두에서 막았고, 글자 입력칸에서만 복사·붙여넣기 메뉴가 그대로 뜹니다.

- PSD 열기: 조정 레이어 중 레벨·곡선·밝기/대비·색조/채도·반전·포스터화·한계값·흑백은 그대로 조정 레이어로 (그라데이션 맵·색상 균형 등은 빈 레이어), 레이어 효과(그림자·획 등)는 빠짐
- PSD 텍스트 레이어는 처음엔 그림으로 열리고, 텍스트 도구로 탭하면 편집 가능한 글자로 바뀜 (글꼴이 없으면 비슷한 글꼴)
- 글자를 원근(자유) 변형하면 그때만 그림 레이어가 됨 (이동·크기·회전은 글자 그대로 유지)

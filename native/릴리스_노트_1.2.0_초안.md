ComicPad 1.2.0 (네이티브 판 베타)

■ 새 네이티브 판을 써 볼 수 있습니다 (베타, 원하는 분만)
- 웹 화면 없이 Windows 에서 바로 도는 새 ComicPad 가 함께 설치됩니다. 펜 입력을 Windows 에서 직접 받아 반응이 더 빠르고, 큰 원고에서도 가볍습니다.
- 업데이트만으로는 아무것도 바뀌지 않습니다. 지금처럼 웹 판으로 켜집니다.
- 써 보려면: 도움말 > 새 네이티브 판 써 보기 (베타)… → "네이티브 판으로 바꾸기". 열던 작품을 그대로 열고, 다음부터 ComicPad 아이콘이 네이티브 판으로 켜집니다.

■ 언제든 돌아올 수 있습니다
- 네이티브 판의 도움말 > 웹 판으로 돌아가기… 를 누르면 다시 웹 판으로 켜집니다.
- ComicPad 를 켤 때 Shift 키를 누르고 있으면 이번만 웹 판으로 열립니다.
- 네이티브 판이 제대로 켜지지 않으면 알려 드리고 웹 판으로 엽니다.
- 이 업데이트 자체도 도움말 > 업데이트 확인 에서 1.1.3 으로 되돌릴 수 있습니다 (되돌리면 늘 웹 판).

■ 작품과 설정은 그대로
- 작품(data 폴더)은 두 판이 같이 씁니다. .cpad 파일은 어느 판에서나 열립니다. 백업·버전 기록도 같은 곳에 쌓입니다.
- 네이티브 판을 처음 켤 때 지금 설정을 가져갑니다: 브러시(내가 만든 것 포함)·필압 곡선·필기감·펜 버튼·단축키·도구 키·화면 구성(간단히/모든 기능, 퀵바, 아래 막대, 원형 메뉴, 작업 화면)·팔레트·최근 색·처음 세팅 등.
- 나중에 웹 판에서 바꾼 설정은 네이티브 판 도움말 > 웹 판 설정 가져오기… 로 다시 가져올 수 있습니다. 네이티브 판에서 직접 바꾼 설정은 덮어쓰지 않습니다.
- 자동 저장은 판마다 따로 남습니다 (네이티브 판은 "이름 (네이티브).cpad").

■ 네이티브 판에 아직 없는 것
- 휴대폰·태블릿 연결(QR), 웹 플러그인(집중선·망점 톤 플러그인 등)은 웹 판에서 쓰세요.
- 베타라 다른 점이나 빠진 기능이 있을 수 있습니다. 도움말 > 문제 보내기 로 알려 주시면 고치겠습니다.

■ 그 밖에
- 창 프로그램(ComicPad.exe)이 바뀌었습니다. 업데이트를 적용한 뒤 ComicPad 를 한 번 완전히 껐다 켜 주세요.
- 업데이트 크기가 전보다 큽니다 (네이티브 판에 .NET 런타임이 함께 들어 있어 따로 설치할 것이 없습니다).

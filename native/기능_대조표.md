# 웹 판 ↔ 네이티브 판 기능 대조표

웹 판(`app/js/`)의 모든 명령·도구·패널·설정을 네이티브 판(`native/ComicPadNative`)과 맞대 본 표. 명령 이름은 웹 판 id (세팅 프리셋·.cpset·단축키 설정·원형 메뉴·아래 막대·자동 액션에서 쓰는 이름)이고, 네이티브 판은 이 id 를 그대로 받아 오른쪽 메뉴를 실행한다 (`Modules/Shell2/WebIds.cs` → `KeyMap.CmdAlias`).

상태: **있음** = 이 작업 전부터 네이티브에 있었음 · **새로 옮김** = 이 작업(Shell2 모듈)에서 옮김 · **다른 작업에서** = 애니·타임랩스·인쇄·전자책·웹툰·WebP/MP4 내보내기, 또는 내용 인식 채우기·AI·사진 자세·버튜버 추적 (동시에 진행 중인 다른 작업 범위라 여기서는 건드리지 않음) · **없음** = 네이티브에 없음 (이유를 적음)

## 요약

- 웹 명령 전체: **272개** (`app.registerCommand` 기준, 같은 id 는 한 번)
- 있음: 153개
- 있음 (키): 6개
- 있음 (다른 작업에서 보강): 44개
- 새로 옮김: 52개
- 다른 작업에서: 7개
- 없음: 10개

## 아직 없는 것과 이유

- `file.download` 프로젝트 파일 다운로드 — 웹 브라우저 전용 (네이티브는 저장 = 파일, 다른 이름으로 저장으로 아무 곳에)
- `file.storage` 저장 위치 · 구글 드라이브 (서버 / 폴더 / 이 기기)… — 서버·구글 드라이브 사본 설정 — 네이티브는 서버 없이 작업물 폴더를 직접 씀 (드라이브 데스크톱 폴더 안에 두면 같은 효과)
- `file.drivePull` 구글 드라이브에서 가져오기… — 서버의 구글 드라이브 사본 기능 — 네이티브는 열기(Ctrl+O)로 드라이브 폴더의 파일을 바로 엶
- `plugins.reload` 플러그인 다시 불러오기 (새로고침) — 웹 JS 플러그인 — 네이티브는 IModule 모듈(다시 빌드)로 확장
- `plugins.folder` 플러그인 폴더 열기 — 웹 JS 플러그인 폴더 — 네이티브는 해당 없음
- `mem.freezeNow` 메모리 절약: 지금 안 쓰는 레이어 압축 — 웹 캔버스 메모리 절약 — 네이티브는 빈 타일을 만들지 않는 타일 메모리라 필요 없음
- `mobile.connect` 휴대폰·태블릿 연결 (QR)… — 휴대폰을 PC 서버에 붙이는 기능 (server.py) — 네이티브 단독 앱에는 서버가 없음
- `mobile.install` 앱으로 설치 (홈 화면/시작 메뉴) — PWA 설치 — 네이티브는 설치 프로그램으로
- `file.local` 기기 임시 저장함 (연결 끊겼을 때 저장된 것)… — 브라우저(기기) 임시 저장함 — 네이티브는 data\autosave 가 같은 역할 (파일 > 최근 작품·자동 저장)
- `test.macroFx` 시험 — 웹 자동 점검 안의 시험용 명령
- 도구 `script` 대본 배치 — 말풍선·텍스트 레이어 자동 배치를 만화 모듈 쪽에 이어야 해서 남김
- 퀵바 "직선 모드"·"각도 스냅" 버튼 — 네이티브 도구는 Shift 키로 (가상 Shift 연결 지점이 없음)

_이 표는 Shell2 시험(`COMICPAD_SHELL2_SELFTEST`)이 쓰는 registry.tsv(실제 등록된 메뉴·도구·패널·별칭)로 만들었다._
